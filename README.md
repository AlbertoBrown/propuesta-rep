# Propuesta Brisa × Repsol 2027

Landing visual para presentar la promoción conjunta de Brisa Festival y Repsol.

- Luz + Gas → entrada gratuita.
- Solo Luz o Solo Gas → 50% de descuento.
- El beneficio queda reservado y se desbloquea tras 4 meses de suministro activo.
- Incluye una simulación de seguimiento móvil y de panel de control.
